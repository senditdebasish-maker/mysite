Site setup

Everything on this page can be changed later from Admin → Storefront and here (sign in as admin). Nothing goes live until you press Complete setup.

How to fix this

The setup API this page needs is: —

  1. Start Apache in the XAMPP Control Panel and open http://localhost/mysite/setup.html.
  2. Confirm that api/, assets/ and the project .htaccess are inside C:\xampp\htdocs\mysite.
  3. For MySQL errors, start MySQL in XAMPP and use the exact database name, host, user and password assigned to your existing database.

2

Gmail SMTP for email codes

PHPMailer sends single-use sign-in codes through your Gmail account.

Use a Google App Password (not your normal Gmail password). Enable 2-Step Verification in your Google account, then create an App Password. This sender credential is stored in protected data/install.json. Test sends an email to this address.

Storefront rules

Delivery charges, cash-on-delivery policy and whether the store is open for orders.

Backups & restore

Use phpMyAdmin to export or restore the MySQL database.

In XAMPP, open http://localhost/phpmyadmin, select your site database, then choose Export to download a backup or Import to restore one. Hosting panels generally provide the same phpMyAdmin Export/Import tools.
