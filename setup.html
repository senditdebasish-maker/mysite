Site setup

Everything on this page can be changed later from Admin → Storefront and here (sign in as admin). Nothing goes live until you press Complete setup.

How to fix this

The setup API this page needs is: —

  1. Restart the Node app after pulling the latest code — Node caches routes at boot, so an old process never sees /api/setup/* even with new files on disk. (cPanel / Passenger: press “Restart” on the app.)
  2. Serve it with the Node server, not a static host: npm start on Node ≥ 22.5. GitHub Pages / Netlify / python -m http.server can show this page but can never run the installer.
  3. Upload the whole repo — setup.html and server/server.js must come from the same version.
  4. Behind a proxy or subpath? Forward /api/* to the app untouched, or open /setup.html?api=/your/subpath/api.
